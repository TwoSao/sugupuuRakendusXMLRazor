# sugupuuRakendusXMLRazor

Family tree ("sugupuu") web application that stores and displays data in **XML**, built with **ASP.NET Core Razor Pages**.

## Tech stack
C# · ASP.NET Core Razor Pages · XML / XSLT

## Getting started
```bash
git clone https://github.com/TwoSao/sugupuuRakendusXMLRazor.git
cd sugupuuRakendusXMLRazor/sugupuuRakendusXML
dotnet run
```
